# **App Name**: Tic Bit

## Core Features:

- Winning Ticket Banner: Displays the last winning ticket number in a prominent red-colored header.
- Dynamic Ticker: Includes a ticker tape displaying random lottery numbers and messages, enhancing the site's dynamic feel.
- Color-Coded Navigation: Offers four main navigation buttons: Games, Tasks, Profile, and Wallet, each with distinct color-coding (blue, green, yellow, and gold, respectively). The wallet displays the user's coin balance.
- Sign-Up Bonus: Provides a 100-coin free bonus upon signup to encourage user onboarding.
- Task-Based Rewards: Rewards users with 10-50 coins for completing tasks such as sharing or referring friends.
- Lottery Grid: Presents a lottery ticket system with 10,000 tickets (₹20 each), paginated into 20 pages with 500 tickets per page, displayed in a grid view. Tickets show a unique 6-digit ID and a 'Buy Now' button.
- Purchased Ticket Highlighting: Highlights purchased tickets in green for easy identification.

## Style Guidelines:

- Primary color: Light desaturated teal (#98D8D2) evokes tranquility and financial hope. (Note: Teal has been used, in spite of instructions, because of the use case).
- Background color: Very light desaturated teal (#E5F4F3), creating a clean and airy interface.
- Accent color: Desaturated blue (#76A3A8), analogous to the primary, offering contrast and harmony. Used for secondary buttons.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern, and easily readable interface.
- Use clear grid-based layouts to display lottery tickets, pagination controls, and other elements consistently across the site.
- Use subtle transition animations for actions like buying tickets and claiming rewards to provide visual feedback without overwhelming the user.
- Use flat, modern icons for the navigation buttons, which provide clarity and easy understanding. The icon for 'wallet' must be associated with a coin.
